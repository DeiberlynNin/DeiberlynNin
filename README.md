### Credit Risk Prediction & MLOps

Contamos con una entidad financiera que me solicita el estudio de sus datos con el fin de crear un sistema de predicción **(Machine Learning)** enfocado en determinar el riesgo crediticio de los clientes nuevos en la entidad. El análisis de sus datos me permitió recopilar información necesaria para entrenar diferentes modelos, seleccionando el modelo "ganador" según la comparativa de métricas claves y no sesgadas 

Finalmente desarrollé el despliegue en producción del modelo y me aseguré a través de una estrutura de codigos limpios que los datos futuros de entrenamiento del modelo, si presentan cambios que podrían afectar su desempeño **generar una alerta de reentrenamiento**.

**Tecnologías:** Python · Machine Learning · FastAPI · Docker · Streamlit · MLOps

### Customer Churn Prediction

Cuento con una entidad financiera que presenta un 20% de clientes que abandonan sus productos (clientes **Churn**). El cliente solicita un sistema de predicción **(Machine Learning)** que permita identificar con tiempo los posibles clientes que puedan tener esta conducta. Por lo que se me permite analizar su datos y encontrar factores claves que permiten el desarrollo del entrenamiento de múltiples modelos de predicción, como también identificar que los clientes con la **mayor cantidad de productos de la entidad**, son los que más abandonan los servicios **(insight de oportunidad de negocio para el departamento de Análisis de Datos)**. 

En el proyecto realicé análisis exploratorio de datos, entrenamiento y optimización de modelos, clustering, reducción de dimensionalidad, comparativa de métricas y varios documentos de recomendaciones a la entidad financiera abordando posibles soluciones para los clientes actuales que cuentan con una cantidad notoria de sus productos.
.

**Tecnologías:** Python · Scikit-learn · XGBoost · LightGBM · CatBoost · Optuna

### Seasonal Product Demand Forecasting

Proyecto final colaborativo de mi cursada Data Science para SoyHenry. Se nos solicitó crear un sistema de recomendación desde una base de datos explorada y seleccionada por nosotros como equipo de trabajo. Luego de múltiples revisiones, optamos por realizar el proyecto con una base de datos sintéticos a través de la API Kaggle, un E-Commerce Sales que presenta problemas del "mundo real" y que necesita de acuerdo al volumen de sus ventas un sistema predictivo de pronóstico de demanda estacional de productos de acuerdo a sus subcategorias. Esto con el fin de apoyar la planificación de inventario y la toma de decisiones de negocio.

Realicé trabajo en equipo constantemente, desde la revisión de los archivos y documentos que realizaban otros compañeros (EDAs, archivos .py, etc), como también diferentes dailies para organizar tareas y cumplir con los diferentes roles del proyecto. Entrené el modelo que decidimos como equipo gestionar en producción (seasonal naive), y gestioné a través de un código limpio y estructurado su demostración a través del aplicativo de Streamlit.

**Tecnologías:** Python · Machine Learning · LightGBM · MLflow · Streamlit
